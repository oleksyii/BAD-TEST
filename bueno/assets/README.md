# assets/

Ці файли не зберігаються в репозиторії (репо публічне). Щоб перезібрати відео, покладіть сюди:

| файл | що це |
|---|---|
| `face_src.jpg` | фото обличчя 640×640 (обличчя по центру, як у вихідному фото) |
| `bueno_src.webp` | фото обгортки Kinder Bueno 1000×1000 з прозорим фоном |

`tools/build.sh` сам завантажить шрифт Rubik і згенерує `face.jpg` та `bueno_wrapper.png`.
